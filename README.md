# DNights.github.io

김아영 포트폴리오 GitHub Pages 사이트입니다.

프로필 README에 정리했던 자기소개, 프로젝트, Focus, Tech Stacks, Contact 내용을 웹 페이지 형태로 구성했습니다.

## MemoryLink 졸업작품 체험

- 포트폴리오: https://kimayeong21.github.io/DNights.github.io/
- MemoryLink 체험판: https://kimayeong21.github.io/DNights.github.io/memorylink/
- 원본 프로젝트: https://github.com/kimayeong21/DigitalLegacy_ManagementService

체험판은 최신 웹 화면을 정적으로 내보낸 버전입니다. 추억 추가·수정·삭제, 검색·태그·즐겨찾기, 타임라인, 추억 다시보기, JSON 백업·복원을 체험할 수 있습니다. 데이터는 현재 브라우저의 localStorage에 저장되며 서버 계정 인증, 기기 간 동기화, 실제 OpenAI 호출은 제공하지 않습니다. 브라우저 데이터를 지우면 기록도 지워지므로 필요한 자료는 JSON으로 내보내세요.

다시 생성하려면 원본 프로젝트에서 `npm run build` 후 `node scripts/export-pages-demo.mjs <이 저장소의 memorylink 폴더 경로>`를 실행합니다.
